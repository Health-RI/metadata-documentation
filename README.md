# Health-RI Metadata Documentation

This repository maintains the human-readable **Health-RI Metadata Model specification** for the **National Health Data Catalogue**. The specification describes the schema's classes, properties, cardinalities, controlled vocabularies, and usage guidance.

## Read the specification

| Resource | Link |
|----------|------|
| Latest published specification | [Read the documentation](https://health-ri.github.io/metadata-documentation/) |
| Previous specification: v2.0.3 | [Read the saved HTML specification](https://health-ri.github.io/metadata-documentation/releases/v2.0.3/) |
| Metadata schema artifacts and releases | [Health-RI/health-ri-metadata](https://github.com/Health-RI/health-ri-metadata) |
| Citable archival record | [Zenodo DOI](https://doi.org/10.5281/zenodo.15395604) |

Saved specifications include their accompanying images and remain available when the latest documentation is updated. See the [version guide](releases/README.md) for the saved version folders and publication procedure.

## Report an issue

Report all issues, including documentation issues, in the [metadata repository's issue tracker](https://github.com/Health-RI/health-ri-metadata/issues).

## How to cite

For the human-readable specification, use the preferred citation in [CITATION.cff](CITATION.cff) or GitHub's **Cite this repository** feature.

For machine-readable schema artifacts, including workbooks and SHACL shapes, use the [metadata repository](https://github.com/Health-RI/health-ri-metadata) and its own `CITATION.cff`. Cite both resources when your work relies on both, and identify the versions used.

## Maintain the documentation

**Start with the [maintainer guide](src/README.md)** for source locations, editing rules, property-table generation, local builds, validation, and workflow diagrams.

Use the [release guide](releases/README.md) to prepare a version, save its HTML and images, register links to previous specifications, and verify publication.
